# Продажа гайда через бота + ЮKassa

Платный гайд «Работа диджея по контракту на Мальдивах» продаётся **автоматически** через
Telegram-бота с оплатой в ЮKassa. Защита от копирования — доставка защищёнными
сообщениями (`protect_content`): их нельзя переслать, скопировать текст или сохранить
(скриншоты Telegram запретить не может — это ограничение платформы, не бага).

## Флоу покупки

1. Кнопка «Купить гайд» на `shmidt01.ru/guide/` → `t.me/<bot>?start=guide`.
2. Бот просит email (нужен для чека 54-ФЗ).
3. Бот создаёт платёж в ЮKassa и присылает кнопку «Оплатить 2000 ₽».
4. Покупатель платит → ЮKassa шлёт webhook `payment.succeeded` на сервер.
5. Сервер перепроверяет платёж через API ЮKassa, отдаёт гайд защищёнными сообщениями,
   помечает покупку доставленной и уведомляет админов.

Код: `server/guide.mjs` (флоу + доставка), `server/guide-content.mjs` (текст гайда),
`server/yookassa.mjs` (клиент API), `server/payments.mjs` (webhook), `server/bot.mjs`
(триггеры), таблица `purchases` (`migrations/0003_purchases.sql`).

> ⚠️ Логика реализована только в `server/` (прод на VPS). Резервный `worker/` намеренно
> не обновлён — при возврате на Cloudflare-путь портировать вручную.

## Что настроить (однократно)

### 1. Бот для сайта
В `.env.production` (или секретом CI) задать `VITE_GUIDE_BOT_USERNAME=<username бота без @>`
и пересобрать фронт. Если пусто — кнопка ведёт в личку `@shmidt01` (ручная продажа).

### 2. ЮKassa
В `/opt/ekaterina-shmidt/infra/shmidt01/.env` на сервере добавить:

```
YOOKASSA_SHOP_ID=<shopId из кабинета>
YOOKASSA_SECRET_KEY=<секретный ключ>
GUIDE_PRICE_RUB=2000
GUIDE_VAT_CODE=1            # 1 = «без НДС» (самозанятые/НПД)
GUIDE_REQUIRE_EMAIL=true    # чек 54-ФЗ; false — без чека
GUIDE_RETURN_URL=https://shmidt01.ru/guide/?paid=1
```

В кабинете ЮKassa → «HTTP-уведомления»: событие **`payment.succeeded`**, URL
**`https://shmidt01.ru/api/payments/yookassa`** (nginx срезает `/api`).

Перевыкатить контейнер API (push в master или ручной деплой).

### 3. Чек 54-ФЗ
Тело чека формируется в `server/yookassa.mjs` (`receipt`). По умолчанию: один предмет
расчёта (услуга), `vat_code=1` (без НДС), оплата полная. Если у Екатерины не самозанятость,
а ИП/ООО с НДС — поменять `GUIDE_VAT_CODE`. Без корректного чека ЮKassa может отклонить
платёж у фискализированного магазина.

## Команды бота (владелец)

- `/sales` — последние покупки (статус, сумма, email, дата).
- `/sendguide <chat_id>` — выслать гайд вручную (фолбэк, если автодоставка не сработала).
  Покупатель должен сначала написать боту `/start`.

## Админ-панель (`shmidt01.ru/admin`)

Веб-панель с входом по паролю (`ADMIN_PASSWORD`). Авторизация — подписанная HMAC
cookie-сессия (`server/admin-auth.mjs`), API под `/api/admin/*` (`server/admin.mjs`),
статика — `admin/` (собирается Vite). Умеет:

- **Статистика:** доставлено гайдов, выручка, оплачено, всего заявок.
- **Покупки:** таблица со статусами (`awaiting_email` → `pending` → `paid` → `delivered`),
  фильтр по статусу, кнопка «Выслать» (повторная доставка на `chat_id`).
- **Настройки:** цена (₽), вкл/выкл продаж, спрашивать ли email — хранятся в таблице
  `settings`, меняются без деплоя. Цена/флаги перекрывают переменные окружения.
- **Текст гайда:** редактор; блоки (отдельные сообщения) разделяются строкой `---`.
  Проверка лимита 4096 на блок. Тест-отправка на свой `chat_id`.

Настройка: в server `.env` задать `ADMIN_PASSWORD` (без него панель отдаёт 503) и
желательно `ADMIN_SESSION_SECRET` (длинная случайная строка; смена разлогинит всех).
Cookie — `HttpOnly; Secure; SameSite=Strict`, поэтому работает только по HTTPS.
nginx менять не нужно: `/admin/` отдаётся как статика, `/api/admin/*` идёт в backend.

## Грабли

- Доставка идемпотентна: повторный webhook на уже доставленную покупку ничего не дублирует.
- Если доставка сломалась, webhook отвечает 5xx — ЮKassa повторяет уведомление (до ~24 ч).
- Скрытая веб-страница `guide/maldives-311da15937d7/` больше не выдаётся покупателям
  (доставка только ботом). Её можно удалить как лишний вектор утечки — но это отдельное
  решение, пока оставлена (noindex).
- Текст гайда в `server/guide-content.mjs` и веб-страница — две копии; при правках
  синхронизировать вручную.
