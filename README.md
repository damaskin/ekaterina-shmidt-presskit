# Ekaterina Shmidt — DJ Presskit

React + Vite one-page press kit with **framer-motion** and **Aurora** WebGL background.

## Stack

- React 19 + TypeScript + Vite
- framer-motion
- Aurora (WebGL simplex noise, CSS fallback)

## Run

```bash
npm install
npm run dev
```

http://localhost:5173

## Build

```bash
npm run build
```

Output: `dist/`

## GitHub Pages

Сайт: **https://damaskin.github.io/ekaterina-shmidt-presskit/**

Деплой через GitHub Actions при push в `master` / `main`. В Settings → Pages источник: **GitHub Actions**.
